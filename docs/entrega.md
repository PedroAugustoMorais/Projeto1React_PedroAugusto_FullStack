**Projeto:** AlugaSom — aluguel de instrumentos musicais.

**Repositório público no GitHub:** (https://github.com/PedroAugustoMorais/Projeto1React_PedroAugusto_FullStack/)

**Integrante:** Pedro Augusto da Silva Morais — RA 2565935.

**Vídeo de apresentação:** (https://drive.google.com/drive/folders/14UenAQxdlNKHPGNmJw-8aX8WYdzQ66Hs?usp=drive_link)

**Hook / funcionalidade implementada:** `useReducer`, utilizado com Context API para gerenciar o catálogo, a seleção de instrumentos e as reservas simuladas.

**API JSON pública utilizada:** Wikidata / MediaWiki Action API, com o endpoint `https://www.wikidata.org/w/api.php` e a ação `wbgetentities`, para carregar nomes e descrições de instrumentos musicais.

**Biblioteca externa:** Material UI.

**Descrição:** aplicação SPA desenvolvida em React.js que consulta uma API pública via AJAX, permite pesquisar e filtrar instrumentos, selecionar quantidades e datas, calcular o valor do aluguel e simular reservas. O histórico é salvo no navegador e pode ser consultado e cancelado.

**Ferramentas de apoio:** uso de ChatGPT / Codex documentado no README.
